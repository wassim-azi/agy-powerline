How the configurator works

This page is an agy statusline generator: it builds the statusline.config.json file that agy-powerline reads on every refresh. The preview above is drawn by the same code that draws your bar in Antigravity CLI, from sample data, so what you see is what agy shows.

Start from a preset, add widgets from the palette, reorder them and open a widget's options with the gear. Pick a theme for your terminal's background, a layout (Pills, Lines or Classic) and a powerline shape. The Sample buttons show the bar when a quota is getting low, and the Width slider shows how it fits a narrow window.

When it looks right, download the file and run npx agy-powerline import statusline.config.json: it shows what will change and asks before applying. Don't have agy-powerline yet? Run npx agy-powerline init first (install guide). Everything happens in your browser: nothing is uploaded, and a share link keeps the config after the #, which browsers never send to a server. Every option is described in the configuration reference.
